# 2.9 寸墨水屏 + ESP32-S3

一块 **296×128 的 1bpp 黑白墨水屏**，用 ESP32-S3 驱动，电脑上一条命令推文字/图片进去。
**已在实物上跑通**（2026-10-27）：全刷 2.26 秒、局刷 0.95 秒、中文正常、无残影错乱。

```
屏：2.9inch e-Paper Module V3   296×128   1bpp   显存 4736 字节
控：ESP32-S3-N16R8             16MB Flash / 8MB PSRAM
总线：4 线 SPI（只写）+ 3 根控制线 + 电源
成本：约 ¥110~150（屏 ¥50~80 + 板 ¥45 + 线材杂项）
```

> 这个项目**以 2.9 寸为主线**。代码里留了 4.2 / 4.26 寸的适配（改两个宏就能编），
> 但那两档**没有实物验证过**，见 [支持其他尺寸](#支持其他尺寸)。

---

## 现在能做什么

1. **推文字**：Windows 上 `.\push.ps1 "第一行|第二行|第三行|第四行"`，屏上立刻换页
2. **推图片**：任意 jpg/png，自动抖动成黑白
3. **整本书按页翻**：`.\push.ps1 -Book novel.txt -Page 3`

中文不用固件字库——**排版全在电脑上做**，固件只收 4736 字节位图。所以换字体、加粗、居中都不用重烧固件。

## 硬件清单

| 件 | 型号 | 说明 |
|---|---|---|
| 墨水屏 | 微雪 2.9inch e-Paper Module（V3，296×128） | 8 脚排线 + 转接板 |
| 主控 | ESP32-S3 DevKitC-1 N16R8（或兼容板） | 原生 USB，无需 USB-TTL |
| 线 | 8 根杜邦线（母-母） | 屏自带排线插在模块上 |
| 电容 | 10µF + 0.1µF（可选） | 并到屏的 VCC-GND，花屏时加 |

## 接线

| 屏模块 | ESP32-S3 | 作用 |
|---|---|---|
| VCC | 3V3 | 3.3V，**不要接 5V** |
| GND | GND | 共地 |
| DIN | GPIO11 | SPI MOSI（屏只写不读，没有 MISO） |
| CLK | GPIO12 | SPI SCK |
| CS | GPIO10 | 片选 |
| DC | GPIO9 | 命令/数据切换（低=命令） |
| RST | GPIO8 | 复位 |
| BUSY | GPIO7 | 高电平 = 忙 |

⚠️ **屏模块丝印顺序是 `BUSY RST DC CS CLK DIN GND VCC`，和官方表格正好相反。按丝印接，不要按网上表格接。**

## 三步跑起来

```powershell
cd epaper29

# 1) 建环境（只做一次）
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install platformio pillow pyserial

# 2) 编译 + 烧写（-Monitor 可选，会打开串口）
.\build.ps1 -Target 29 -Board s3 -Upload

# 3) 推一页
.\push.ps1 "第一行|第二行|第三行|第四行"
```

串口看到下面这几行、屏上出图，就是全部跑通：

```
=== Ink firmware (2.9inch 296x128 / UC8151D/SSD1680) boot #1 ===
[ep29] init ok (SSD1680 + host LUT)
[ep29] refresh 4736 bytes, 2262 ms
READY.
```

**判断技巧**：正常全刷恒定 **2261~2263 ms**；如果只有几毫秒，说明控制器没执行刷新（初始化没被接受），别去查数据。

## 日常推送

| 想要 | 命令 |
|---|---|
| 推文字（`\|` 分行） | `.\push.ps1 "第一行\|第二行\|第三行\|第四行"` |
| 只看效果不推屏 | `.\push.ps1 "文字" -Preview out.png -NoPush` |
| 字大一点 / 居中 | `.\push.ps1 "文字" -Size 20 -Center` |
| 推 txt（每行一行） | `.\push.ps1 -File notes.txt` |
| 推图片 | `.\push.ps1 -Image D:\photo.jpg` |
| 整本书翻页 | `.\push.ps1 -Book novel.txt -Page 3` |
| 指定字体 | `.\push.ps1 "文字" -Font C:\Windows\Fonts\simhei.ttf` |

三个必知：

1. 每次推送**板子会重启一次**（串口打开即复位，S3 硬件行为）——现象是"闪回首页 → 约 2 秒后变新内容"
2. 控制台中文乱码不用管，屏上和 `-Preview` 的图都是对的
3. **成功标志是回 `OK frame`**，只回 `[ep29] refresh ...` 不算（那可能只是开机画首页）

## 故障速查

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 全刷几毫秒、屏不动 | 初始化缺 `0x12/0x11/0x44/0x45/0x4E/0x4F` | 看 `epd.cpp` 的 `e29_init()`，一条别少 |
| 耗时正常但屏不变 | 显存几何反了（屏是 16 字节×296 行） | 见 `e29_build_mem()` |
| 推完图变回首页 | 串口 DTR/RTS 复位了板子 | `push.py` 已处理：等 `READY.` 再发 |
| 局刷后画面乱 | 全刷没同步写 `0x26`（旧图） | 见 `e29_show()`：`0x24` 和 `0x26` 都要写 |
| 花屏/条纹 | 供电不稳 / SPI 太快 | VCC 并 10µF+0.1µF；`EPD_SPI_HZ` 降到 2MHz |
| 找不到串口 | 数据线只能充电 | 换线；试板上另一个 Type-C |

更多症状见 [docs/00-完全手册.md](docs/00-完全手册.md) 第 3.4 节和第 11 章。

## 支持其他尺寸

代码本就按"尺寸无关"写的，换屏只改 `firmware/src/board_config.h` 里的 `EPD_MODEL`，
或者直接用预置环境：

| 尺寸 | 环境 | 状态 |
|---|---|---|
| **2.9" 296×128** | `esp32-s3-29` | ✅ **实物验证，本项目主线** |
| 4.2" 400×300 | `esp32-s3` | ⚠️ 只编译通过，无实物验证 |
| 4.26" 800×480 | `esp32-s3-426` | ⚠️ 只编译通过，需要 S3 + PSRAM |

4.2 寸是另一个控制器（UC8176），初始化和波形都不一样，**不能只改尺寸就指望能亮**，要按
[完全手册](docs/00-完全手册.md) 第 7 章重新核对寄存器。
