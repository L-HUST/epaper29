# 13 中文字库（固件 UI）

> 状态：M5 已实现（2026-11-05）。仅用于**菜单/设置/跳页/书库/休眠页**等固件界面。
> 正文和书名仍然由 PC 端渲染成位图，不经过这套字库。

## 为什么需要

固件原来只有 5×7 ASCII。M5 要求界面全中文，但设备不能调用 Windows 字体，
所以把 UI 用到的汉字做成 **1bpp 点阵子集**，编进固件。

## 字体来源

- 字体：**Noto Sans SC**（SIL Open Font License 1.1）
- 本机路径：`C:\Windows\Fonts\NotoSansSC-VF.ttf`
- 只抽取界面文案里出现的汉字，不嵌入整套字库
- 不嵌入宋体/微软雅黑等 Windows 商业字体

## 生成

```powershell
cd D:\04-Code\08-deepseek-harness\epaper29
.\.venv\Scripts\python.exe tools\gen_cjk.py
```

输出：`firmware/include/font_cjk.h`

包含：

| 字号 | 用途 | 字宽 × 字高 |
|---|---|---|
| 15 | 菜单项、设置项、页标题 | 15 × 15 |
| 12 | 页脚、提示、页码前缀 | 12 × 12 |

每个字 1bpp，1 = 墨，0 = 纸。

## 新增中文文案

1. 把新汉字加到 `tools/gen_cjk.py` 的 `CHARS` 字符串
2. 重新运行生成脚本
3. 重新编译烧写

漏字时固件会画 `?`，不会崩；但文案会缺字，提交前要检查。

## 渲染接口

`epd.draw_cjk_text(x, y, "中文", color, size)`：

- UTF-8 输入
- 汉字走内嵌点阵
- ASCII 自动回退到 5×7 字库，并在 15/12px 行高内垂直居中
- `epd.cjk_text_width()` 用于右对齐

## 已知限制

- 字库只覆盖 UI 文案，不是通用中文输入/排版
- 12px 点阵笔画较细，适合短提示，不适合长句
- 新增字体文件或字库后要重新编译；字库在 flash，不占 RAM
