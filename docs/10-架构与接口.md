## 1. 目标与非目标

### 1.1 v1 目标

1. 开机进入书库，选书后能连续阅读。
2. 4 个按键完成翻页、选择、返回、休眠/关机。
3. 断电/休眠后恢复上次的书和页码。
4. PC 能把 `.epg` 传进内部 flash，并能在书库看到。
5. 保持现有 `push.ps1` / `read.py` / 串口协议可用。
6. 代码结构支持后续加 SD、WiFi、BLE、自研板，而不改阅读器核心。

### 1.2 非目标（v1 不做）

- SD 卡驱动与双卷书库。
- WiFi / BLE 传书。
- 充电、电池电量、硬件自锁关机。
- 设备端中文排版、TXT/EPUB 直接解析。
- 字典、书签、阅读统计、封面缩略图。
- OTA 的实际实现（只预留分区）。

## 2. 分层架构

```
┌────────────────────────────────────────────────────┐
│ App 层                                              │
│  App / ScreenManager / Screens                     │
│  Home  Library  Reader  Menu  Settings  Transfer   │
├────────────────────────────────────────────────────┤
│ Core 层（不依赖 Arduino，可 host 测试）              │
│  BookMeta  BookRepository  Document  ReadingState  │
│  KeyEvent / KeyMap  BookImporter                   │
├────────────────────────────────────────────────────┤
│ Platform 接口层                                      │
│  IDisplay  IStorage  IInput  IPower  ITransfer     │
├────────────────────────────────────────────────────┤
│ ESP32 适配层                                         │
│  EpdDisplay  LittleFSVolume  GpioInput             │
│  DeepSleepPower  SerialTransfer  BoardDevKit       │
└────────────────────────────────────────────────────┘
```

### 2.1 依赖规则

1. **Core 不 include Arduino**：`BookMeta`、`Document`、`BookRepository`、`KeyMap` 只用标准 C/C++。
2. **App 只依赖 Core + Platform 接口**，不直接调用 `LittleFS`、`SD`、`digitalRead`、`epd`。
3. **Platform 适配层**把 Arduino/ESP-IDF 包起来；换板、换屏、换传输方式只改这一层。
4. **屏幕之间不互相持有**；由 `ScreenManager` 负责 push/pop。
5. **不用动态插件系统**；功能用编译开关和接口实现隔离，保持固件小。

### 2.2 模块职责

| 模块 | 职责 | 不做什么 |
|---|---|---|
| `App` | 初始化、事件循环、屏幕调度、电源/串口 tick | 不画像素、不读文件 |
| `ScreenManager` | 屏幕栈、进入/退出、脏标记 | 不处理按键语义 |
| `Home/Library/Reader/Menu` | 各屏交互与绘制 | 不直接打开文件 |
| `BookRepository` | 扫描卷、读头、排序、最近列表 | 不渲染页面 |
| `Document` | 页数、按页产出 4736B 帧 | 不知道 UI/按键 |
| `StorageVolume` | 一个 `fs::FS*` + 名称/可写性 | 不决定书库结构 |
| `BookImporter` | 收字节、校验、临时文件、rename | 不关心串口/WiFi |
| `Input` | 扫描、消抖、短按/长按/重复 | 不决定动作 |
| `PowerManager` | 空闲计时、深睡、唤醒原因、电量 | 不画电池图标 |
| `Board` | 引脚、自锁、ADC、USB 检测 | 不读按键语义 |
| `Display` | 全刷/局刷、sleep、帧缓冲 | 不排版 |

## 4. 核心接口

> 下面是接口草案，不是最终代码；实现时可以按内存/编译成本微调，但职责边界不变。

### 4.1 存储卷

```cpp
struct StorageVolume {
    const char* name;      // "flash" / "sd"
    fs::FS*     fs;        // LittleFSFS 或 SDFS，都继承自 fs::FS
    bool        writable;
};

class StorageManager {
public:
    bool begin();                       // 挂载 flash，尝试挂载 sd
    StorageVolume* volumes();
    size_t volumeCount() const;
    StorageVolume* primaryWritable();   // 优先 sd，否则 flash
    uint64_t freeBytes(StorageVolume& v);
};
```

已确认：ESP32 Arduino 的 `SDFS` 和 `LittleFSFS` 都继承自 `fs::FS`，`File` 也是同一个类型，
所以上层可以用统一的 `fs::FS*` / `fs::File`，不需要为 SD 写第二套文件 API。

约定：

- 每个卷的根目录下都有 `/books`、`/system`。
- 上层只写 `books/xxx.epg` 这种相对路径，不写 `/littlefs/...` 或 `/sd/...`。
- `LittleFS.begin(false, "/littlefs", 10, "spiffs")`：**挂载失败不自动格式化**。
- 只有用户在设置里明确选择“格式化”才调用 `LittleFS.format()`。

### 4.2 书元数据

```cpp
enum class BookLocation : uint8_t { Flash, Sd };

struct BookMeta {
    char         id[17];       // 8 字节 hash 的 hex，含结尾 0
    char         title[64];    // UTF-8
    char         author[20];   // UTF-8
    char         path[64];     // 相对卷根的路径，如 "books/a1b2c3d4.epg"
    uint32_t     pageCount;
    uint32_t     sourceCrc;
    uint32_t     layoutHash;
    BookLocation location;
};
```

`BookRepository`：

```cpp
class BookRepository {
public:
    bool scan(StorageManager& storage);          // 只读每个 .epg 的 128B 头
    size_t count() const;
    const BookMeta* at(size_t i) const;
    const BookMeta* findById(const char* id) const;
    bool remove(const BookMeta& meta);
    void reload();
};
```

- 扫描 `books/*.epg`，读头，不读整本；50 本书应在 1 秒内完成。
- 排序：最近阅读（NVS 里的 8 个 id）→ 书名。
- 同 ID 在 flash 和 SD 都存在时，SD 优先；UI 显示 `[SD]` 标记。
- 书库清单不是必须文件；`.epg` 头自带 title/pageCount，扫目录即可恢复。

### 4.3 文档

```cpp
struct Frame {
    uint8_t* data;      // 4736B，1=白，0=黑，行优先，stride=37
    uint16_t stride;
    uint16_t height;
};

class Document {
public:
    virtual ~Document() = default;
    virtual bool open(const BookMeta& meta) = 0;
    virtual uint32_t pageCount() const = 0;
    virtual bool renderPage(uint32_t index, Frame& out) = 0;
    virtual void close() = 0;
};
```

实现：

- `PagePackDocument`：v1 唯一实现。读页表 → 读数据 → 可选 RLE 解压 → CRC16 → 填 `Frame`。
- `TextDocument`：v2，设备端断行 + 字库；UI 不改。
- `EpubDocument`：v3，或由 PC 先转 `.epg`。

`ReaderScreen` 只持有 `Document*`，不知道文件是 flash 还是 SD。

### 4.4 屏幕

```cpp
class Screen {
public:
    virtual ~Screen() = default;
    virtual void enter() = 0;
    virtual void leave() = 0;
    virtual bool onKey(const KeyEvent& e) = 0;  // true = 已消费
    virtual void tick(uint32_t nowMs) = 0;
    virtual void draw(Canvas& canvas) = 0;
};
```

- `ScreenManager` 维护栈，深度最多 4。
- 屏幕通过返回值表达 `Push/Pop/Replace`，不直接操作栈。
- `draw()` 只画到 1bpp `Canvas`；`App` 决定全刷/局刷。
- 只有 `dirty` 时才刷屏，避免每 tick 都刷。

### 4.5 板级

```cpp
class Board {
public:
    virtual ~Board() = default;
    virtual void begin() = 0;
    virtual void holdPower() = 0;        // v2 自锁；v1 空实现
    virtual void releasePower() = 0;
    virtual int  batteryMilliVolts() = 0; // v1 返回 -1
    virtual bool usbPresent() = 0;
};
```

- `BoardDevKit`：v1；无电池/自锁，`usbPresent` 可返回 true。
- `BoardCustom`：v2；P-MOS 自锁、TP4056、ADC、充电状态。
- `PWR_HOLD` 在 `BoardCustom::begin()` 最前面拉高，早于串口/屏初始化。

### 4.6 输入

```cpp
enum class KeyId : uint8_t { Prev, Next, Ok, Power };
enum class KeyType : uint8_t { Down, Up, Short, Long, Repeat };

struct KeyEvent {
    KeyId   id;
    KeyType type;
    uint16_t heldMs;
};

class Input {
public:
    void begin();
    bool poll(KeyEvent& out);   // 非阻塞；队列空返回 false
    void scan(uint32_t nowMs);  // 10ms 调用；消抖/长按/重复
};
```

- 消抖 20ms；长按 800ms；重复 500ms；队列深度 8。
- `Power` 长按由 `PowerManager` 全局处理，不进入普通屏幕。
- `epd.wait_busy()` 期间也调用 `Input::scan()`，避免 2.26 秒全刷丢键。

### 4.7 导入

```cpp
class BookImporter {
public:
    bool begin(const char* volumeName, const char* path,
               uint32_t size, uint16_t crc);
    bool write(const uint8_t* data, size_t len);
    bool finish();   // 校验 + rename + repository.reload()
    void abort();
};
```

- 先写 `path.tmp`，CRC 和页头校验通过后 `rename` 到正式名。
- 空间不足/校验失败时删除临时文件，返回明确错误码。
- 串口、WiFi、BLE 都调同一个 `BookImporter`；它们只负责传输字节。

### 4.8 应用事件循环

```cpp
void App::loop() {
    KeyEvent e;
    while (input.poll(e)) {
        if (power.handleKey(e)) continue;
        screenManager.current()->onKey(e);
        dirty = true;
    }

    serial.poll();          // 现有推图/文本命令
    screenManager.current()->tick(millis());
    power.tick();

    if (dirty) {
        screenManager.current()->draw(canvas);
        display.flush(needFull ? FULL : PARTIAL);
        dirty = false;
    }
    delay(5);
}
```

- v1 单线程、协作式，不上 RTOS 任务。
- WiFi 后置时，HTTP 任务只投递事件/写文件，不直接刷屏；显示始终在主循环。
- `needFull` 由 `ReaderScreen` 的残影计数和屏幕类型决定。

## 5. 数据格式：`.epg` v1

### 5.1 文件头（128B）

| 偏移 | 大小 | 字段 | 说明 |
|---|---|---|---|
| 0 | 4 | magic | `"EPG1"` |
| 4 | 2 | version | 1 |
| 6 | 2 | headerSize | 128 |
| 8 | 2 | width | 296 |
| 10 | 2 | height | 128 |
| 12 | 2 | stride | 37 |
| 14 | 2 | flags | bit0=压缩；其余保留 |
| 16 | 4 | pageBytes | 4736 |
| 20 | 4 | pageCount | 页数 |
| 24 | 4 | pageTableOffset | 128 |
| 28 | 4 | dataOffset | 128 + pageCount×8 |
| 32 | 4 | layoutHash | 排版/字体/渲染器版本 |
| 36 | 4 | sourceCrc32 | 源文本 CRC，书变了重置进度 |
| 40 | 64 | title | UTF-8，NUL 填充 |
| 104 | 20 | author | UTF-8，NUL 填充 |
| 124 | 4 | reserved | 0 |

### 5.2 页表

每页 8 字节：

```text
u32 offset        文件内绝对偏移
u16 storedSize    压缩后字节数；未压缩=4736
u16 crc16         解压后 4736B 帧的 CRC16-CCITT
```

- 页表长度 `pageCount×8`；3000 页约 24KB。
- 随机翻页：`seek(offset)` → 读 `storedSize` → 解压 → 校验 → 填 `Frame`。
- 每页 CRC 用于 SD 卡位翻转/半写检测；坏页只影响一页，不拖垮整本。

### 5.3 压缩

v1 用 PackBits：

- `0..127`：后面 `n+1` 个原字节
- `129..255`：重复下一个字节 `257-n` 次
- `128`：空操作

设计要点：

- 文字页通常 5–15 倍；图片/抖动页可能 1–2 倍，最坏略大于原图。
- 解压是单遍内存拷贝，4736B，毫秒级。
- `flags.bit0=0` 时 `storedSize=4736`，`pack.py` 可先写不压缩；格式不变。

### 5.4 书库与进度

```text
/books/<id>.epg          页包
/system/settings.bin     设置备份（可选）
/system/sleep.bmp        休眠图（可选）
/system/font.fnb         字库（v2）
```

- 不强制 `library.json`；扫 `.epg` 头即可。
- 进度存 NVS：
  - `last_id`（≤15 字符）
  - `last_page`（u32）
  - `last_layout`（u32）
  - `full_cnt`（u16，残影计数）
  - `sleep_to`（u16，分钟）
- 每 5 页或休眠/关机时写一次；不要每页写 flash。
- `layoutHash` 不匹配时从第 1 页开始，并提示"排版已更新"。

### 5.5 容量账

| 内容 | 大小 |
|---|---|
| 1 页原始位图 | 4736B |
| 1 页文字（RLE 后） | 约 300–800B |
| 3000 页页表 | 24KB |
| 30 万字小说原始 | 约 3000 页 / 14MB（不压缩） |
| 同上 RLE 后 | 约 1–2.5MB |
| 内部 11.9MB | 约 2400 页原始；RLE 后通常 1 万页以上 |

导入前检查 `freeBytes`，至少保留 10% 余量；放不下就明确报错，不截断。

## 6. 启动与运行流程

### 6.1 冷启动

1. `Board::begin()`：v1 空；v2 先拉高 `PWR_HOLD`。
2. `Display::begin()`：`epd.begin()`；全刷一次首页/书库。
3. `StorageManager::begin()`：挂载 LittleFS；SD 后置。
4. `BookRepository::scan()`：读 `/books/*.epg` 头。
5. 读 NVS：上次书/页；存在且有效 → 直接进阅读器；否则进书库。
6. 打印 `READY.`（兼容 `push.py`）。
7. 进入事件循环。

### 6.2 屏幕流

```
Boot
 ├─ 有上次进度 ──→ Reader
 └─ 无 ──→ Library ──OK──→ Reader
                 │              │
                 │              ├─ OK ──→ Menu ──→ Settings
                 │              │             └──→ Back
                 │              └─ POWER ──→ Sleep
                 └─ POWER ──→ Sleep
```

- `Library`：4 行/页；PREV/NEXT 移动选择；OK 打开；POWER 休眠。
- `Reader`：PREV/NEXT 翻页；OK 菜单；长按 OK 书签（v1 可先不做）；POWER 短按休眠/长按关机。
- `Menu`：v1 只启用 `Reading settings` / `Back`；`Contents` / `Bookmarks` 作为后续 item 预留，不改菜单框架。
- `Settings`：刷新节奏、休眠时间、电池、About；v1 只读+少量可改。
- `Sleep`：保存状态 → `epd.sleep()` → 深睡（v1）或断电（v2）。

### 6.3 串口"远程显示"模式

为保持现有功能：

- 收到 `0xAA55` 帧 → 直接 `display_full()`，显示 PC 推的图；不强制切屏。
- 收到 `T|...` → 现有 ASCII 排版 + 局刷。
- 收到 `F` → 全刷；`S` → 休眠。
- 任意按键 → 退出远程模式，回到书库/阅读器。
- `READY.` 仍在初始化完成后打印；`push.py` 的 `wait_ready()` 不受影响。

## 7. 按键

### 7.1 引脚

| 键 | GPIO | 说明 |
|---|---|---|
| PREV | 4 | RTC GPIO，`ext1` 可唤醒 |
| NEXT | 5 | RTC GPIO |
| OK | 6 | RTC GPIO |
| POWER | 15 | RTC GPIO；不要同时开 UART0 硬件流控 |
| GND | GND | 所有键另一端共地 |

- `INPUT_PULLUP`，按下拉低。
- 每个键并 100nF 到 GND；长线加 1k 串联（可选）。
- 产品板建议再加 10k 外部上拉。

### 7.2 事件

| 事件 | 判定 | 用途 |
|---|---|---|
| Short | 按下后 20–800ms 释放 | 翻页/选择 |
| Long | 按住 ≥800ms | 菜单/书签/关机 |
| Repeat | 长按后每 500ms | 连续翻页 |
| Down/Up | 原始边沿 | 唤醒/组合键 |

- 消抖 20ms；队列深度 8；重复事件合并，避免堆积。
- 刷新期间 `wait_busy` 调用 `Input::scan()`；按键不丢。
- 深睡唤醒用 `ext1`（4/5/6/15，ANY_LOW）；醒来用 `esp_sleep_get_ext1_wakeup_status()` 判断哪个键。

### 7.3 映射

| 场景 | PREV | NEXT | OK | POWER |
|---|---|---|---|---|
| Library | 上移 | 下移 | 打开 | 休眠 |
| Reader | 上一页（长按上一章） | 下一页（长按下章） | 菜单（长按书签） | 短按休眠 / 长按关机 |
| Menu | 上移 | 下移 | 进入/切换 | 返回 |
| Settings | 上移 | 下移 | 切换 | 返回 |
| Transfer | — | — | — | 退出 |

## 8. 电源

### 8.1 v1：DevKit 深睡

- 空闲 5 分钟（可配）→ 保存 → `epd.sleep()` → `esp_deep_sleep_start()`。
- 唤醒源：4 个按键（`ext1`）；不使用定时唤醒。
- 唤醒后：
  - 读 NVS 恢复书/页。
  - 如果页面没变，不重绘，直接等按键。
  - 如果页面变了，`epd.begin()` 后局刷；残影明显则全刷。
- 待机电流取决于 DevKit 的 LDO，可能 mA 级；先实测，不承诺 µA。

### 8.2 v2：自研板

```
LiPo → 保护板 → TP4056 → ME6211 3.3V → P-MOS → 3V3
                                      ↑
                            按键 / GPIO21 → NPN → P-MOS 栅极
```

- `setup()` 第一行 `PWR_HOLD` 拉高自锁，再初始化串口/屏。
- 长按 POWER 1.5 秒：保存 → `epd.sleep()` → `PWR_HOLD` 拉低断电。
- USB 插入时不要硬切，改成深睡。
- 电池 ADC：1M/1M 分压到 **GPIO1**（不要 GPIO3，strapping 脚），100nF。
- 3.5V 低电提醒；3.4V 保存后关机。
- LDO 选 ME6211/XC6206，避免 AMS1117 的大静态电流。

### 8.3 电源状态机

```
ACTIVE ──空闲超时/短按POWER──→ SLEEP
ACTIVE ──长按POWER──→ OFF（v2）
SLEEP  ──任意键──→ ACTIVE（恢复上次页）
OFF    ──POWER──→ BOOT（v2 自锁）
```

## 9. 分区与 OTA

当前 [partitions_16mb.csv](../firmware/partitions_16mb.csv) 已改为 2.5MB app0 + 2.5MB app1 + 10.875MB FS，
并已整片擦除、重烧过一次：

| 分区 | 偏移 | 大小 | 用途 |
|---|---|---|---|
| bootloader + 分区表 | 0x0 | 约 64KB | 启动 |
| nvs | 0x9000 | 0x5000（20KB） | 设置/小数据 |
| otadata | 0xE000 | 0x2000（8KB） | OTA 状态 |
| app0 | 0x10000 | 0x280000（2.5MB） | 固件本体（系统占这里） |
| app1 | 0x290000 | 0x280000（2.5MB） | OTA 备用，目前空 |
| spiffs/LittleFS | 0x510000 | 0xAE0000（10.875MB） | 书和上传文件 |
| coredump | 0xFF0000 | 0x10000（64KB） | 崩溃转储 |

**不要把“内存”和“分区”混在一起：**

| 名称 | 位置 | 作用 | 掉电 |
|---|---|---|---|
| heap | 芯片内部 SRAM（约 0.34MB） | 程序变量、栈、缓冲 | 丢 |
| PSRAM | ESP32-S3 模组内的 8MB SPI PSRAM | 大缓冲/图片缓存，当前未用 | 丢 |
| LittleFS | 16MB flash 里的 10.875MB 分区 | 存 `.epg` 书 | 不丢 |

板子是 **ESP32-S3-DevKitC-1 N16R8**：16MB flash + 8MB PSRAM。
PSRAM 是模组自带的一颗芯片，**不是 SD 卡**；没有插 SD 也能看到 8MB。
用户上传的书只进 **LittleFS `/books`**，不会进 heap 或 PSRAM。

- 当前固件约 0.37MB，app0 是 2.5MB，余量给 WiFi/BLE/UI。
- FS 总共 10.875MB；《心流》5.97MB 时还剩约 4.86MB。
- OTA 实现后置；先保证 `app1` 存在，未来 WiFi 升级不用再擦用户数据。
- C3 环境用默认分区，不受影响。

## 10. 兼容性契约：已有功能会变吗？

**对外行为不变**：

| 现有能力 | v1 之后 |
|---|---|
| `push.ps1 "文字"` | 仍然可用；串口 `0xAA55` 帧照旧 |
| `push.ps1 -Book ... -Page N` | 仍然可用；PC 端整屏推图 |
| `read.py` 键盘翻页 | 仍然可用；`send_frame` / `READY.` 不变 |
| `T\|x,y,scale\|...` | 仍然可用；ASCII 局刷 |
| `F` 全刷 / `S` 休眠 | 语义保留 |
| 全刷 ~2.26s、局刷 ~0.95s | 不变；不动面板时序 |
| 4.2 / 4.26 编译 | 保持编译通过；新功能只保证 2.9 寸 + S3 |

**内部会变**：

1. `main.cpp` 拆成 `App` + `SerialTransfer`；串口协议代码搬家，但字节级行为不变。
2. `epd.cpp` 修两个 bug：
   - 2.9 寸 `display_full()` 在 `_asleep` 时没有 `begin()`；
   - `display_partial()` 同样绕过了唤醒。
3. `epd.cpp` SPI 初始化改成一次 `SPI.begin(SCK, MISO, MOSI, -1)` + 成对事务，
   为 SD 共用总线做准备；v1 不挂 SD，但先把路铺好。
4. 开机从"uptime 首页"改为"书库/上次阅读页"；`READY.` 仍在初始化后打印。
5. `IDLE_SLEEP_MS` 从 0 改为 300000（5 分钟）；调试时可设 0 关闭。
6. `S` 休眠从"定时 30 秒唤醒"改为"按键唤醒"；更符合阅读器，省电。
7. `EPD_HAS_KEYS` 从死宏变成真实功能；`EPD_HAS_SD` v1 仍为 0。

**不会变**：

- 屏幕分辨率、显存几何、转置方式。
- 全刷/局刷命令序列和波形。
- `push.py` 的渲染/分页结果（除非主动改排版，按 AGENTS 规则 bump `CACHE_VER`）。
- 现有文件布局和构建命令。

## 11. 扩展点

| 要加的东西 | 加在哪里 | 上层要不要改 |
|---|---|---|
| SD 卡 | `SdVolume` + `StorageManager` 多卷 | 不改；书库自动合并 |
| WiFi 传书 | `WifiTransfer` + 现有 `BookImporter` | 不改；只多一个 Transfer 屏 |
| BLE 传书/遥控 | `BleTransfer` / `BleRemote` | 不改 |
| TXT 直接阅读 | `TextDocument` + 字库 | 不改 Reader |
| EPUB | `EpubDocument` 或 PC 转 `.epg` | 不改 Reader |
| 自研板/充电 | `BoardCustom` | 不改 App |
| 触摸/编码器 | 新 `Input` 实现，产出同样 `KeyEvent` | 不改 Screen |
| 书签/统计/字典 | 新 Screen + NVS/文件 | 不改存储/阅读核心 |

原则：**新功能加适配器，不改核心接口**；接口稳定，实现可替换。

## 13. 风险与不做的事

| 风险 | 影响 | 规避 |
|---|---|---|
| 2.9 寸局刷固定 ~948ms | 菜单移动慢 | v1 接受；v2 做窗口局刷 |
| 内部 flash 容量小 | 书放不下 | RLE + 导入前检查 + 明确报错；SD 后置 |
| SD 与屏共用 SPI | 花屏/卡失败 | 事务、CS 上拉、100µF、4MHz 起 |
| 电源自锁设计错误 | 关不掉/掉电 | v2 再上；先面包板；LTC2954 可选 |
| 中文字库/UI | 书名乱码 | 英文 UI + 书名位图条；字库后置 |
| GPL 污染 | 许可证 | 不抄 GPL 代码；MIT 项目保留声明 |
| 改分区 | 全片擦除 | 现在改；先备份；文档写清 |
| NVS 写太频繁 | 寿命 | 每 5 页/休眠写一次 |
| C3 构建被弄坏 | 回归 | 新功能用 `BOARD_SEL`/`ENABLE_*` 包起来 |

不做：

- 不做通用 OS/插件系统/多任务调度。
- 不做设备端 EPUB，直到页包方案稳定。
- 不做 WiFi 常开、BLE 主传书。
- 不做每页写进度、每页全刷。
- 不把 `LittleFS`/`SD` 路径散落在 UI 代码里。
